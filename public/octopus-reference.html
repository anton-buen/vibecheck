Usage Notes

  • Favicon: Used in browser tabs and bookmarks
  • Header Logo: 36px floating octopus in the navigation
  • Pulse Board Avatars: 50px octopus icons showing user moods
  • Main Check-In Mascot: 120px interactive mood-changing octopus
  • PWA Icons: 192px and 512px for mobile home screen
Design Philosophy:

The angry/grumpy octopus represents the vulnerability of admitting you're NOT "Okay lang." It's intentionally expressive and emotive — breaking through the hiya barrier with honest, unfiltered emotions. The reversible plushie concept shows we can flip between feelings.
